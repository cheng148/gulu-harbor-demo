## 真人模型暴露的Bad Case

1. 单个多选值有时返回字符串而不是数组，例如`SHORT_HAIR`。修复：只对多值画像槽位把单个字符串规范为单项数组，并新增回归测试。
2. “中等花费”曾被错误写入必须为数字的`monthlyBudgetCny`。修复：金额槽位拒绝非整数；提示明确把定性投入写入`ongoingInvestmentWillingness`，不得猜测预算。
3. 模型曾生成匹配算法不认识的`WORKDAY_LIMITED_TIME`，也曾对已确认回答返回空值。修复：明确匹配标签表，语义校验失败时最多重试一次。
4. 一次第5轮过敏回答连续两次未通过Schema。系统按预期返回可重试错误，未提交失败轮次；同句最小探针随后通过。
5. 旧自动化夹具仍使用`TIME_FLEXIBLE`、`ACTIVE`等早期标签。已迁移到正式匹配标签，原先验证的动态追问、冲突和用户纠正行为不变。
