# 咕噜港演示脚本

## 1. 先选择演示方式

推荐优先使用本地Mock模式。它会运行真实会话、追问、SQLite、过滤、评分、排序和页面，只把DeepSeek替换成固定回答，因此最稳定，也不会消耗额度。

只有需要专门展示真人模型理解能力时才切换DeepSeek。真人模式可能受网络、额度和模型波动影响；不要把Key展示在屏幕、终端历史、录屏或聊天中。

## 2. 开场30秒

可以直接这样说：

> 咕噜港是一款面向养宠新手的AI选宠Web App Demo。它不会让用户一次填完长问卷，而是从自然表达开始，通过3个核心问题加最多1个真正会改变推荐的问题，逐步整理生活方式。大模型负责听懂和表达，硬约束、下一问、匹配等级和排序由可测试代码决定。最后给出“品种或类型方向 + 模拟商家候选宠物”两层建议，同时讲清适合点、要接受的代价和不匹配点。

## 3. 三分钟主流程

| 步骤 | 页面操作 | 同时说明什么 |
| --- | --- | --- |
| 1 | 打开首页 | 首页、市场、用品、社区、会员中心和“我的”构成产品外壳；交易数字与档案都明确是Demo虚拟数据 |
| 2 | 点击“去聊聊” | AI选宠是唯一做深的真实核心，不是调查问卷 |
| 3 | 输入“我想认识一只成年英国短毛猫，偏中等体型和短毛。” | Agent会提取初始描述，已经知道的信息不会故意重复问 |
| 4 | 输入“工作日能留出一些时间，希望活动量不用太高。” | 每轮只问一个当前最有价值的问题 |
| 5 | 输入“我喜欢安静一点的互动，待在附近陪着就很好。” | 画像关注个人与宠物怎样相处，不把表达热烈程度当成额外分数 |
| 6 | 输入“我能接受规律梳毛和中等花费，没有绝对不能接受的日常负担。” | 用户愿意调整某项差距会被记录，但不会清除其他冲突 |
| 7 | 输入“猫狗都不过敏。” | 过敏放在正式推荐前确认，已知时不会重复询问 |
| 8 | 查看结果 | 先看品种／类型方向，再认识每个方向的一只具体模拟候选；页面不显示内部精确分 |
| 9 | 点击“修改条件再看看”，改变互动节奏并保存 | 系统重新计算；结果成员可以不变，但理由和变化说明必须更新 |
| 10 | 打开市场、用品、社区和“我的” | 这些是可点击原型；真实下单、支付、发帖、会员和商家联系统一提示暂未开放 |

## 4. 建议使用的五轮输入

1. `我想认识一只成年英国短毛猫，偏中等体型和短毛。`
2. `工作日能留出一些时间，希望活动量不用太高。`
3. `我喜欢安静一点的互动，待在附近陪着就很好。`
4. `我能接受规律梳毛和中等花费，没有绝对不能接受的日常负担。`
5. `猫狗都不过敏。`

这组输入是稳定演示路径，不代表Agent只能理解这些句子。自动浏览器测试会用同一主流程验证中文输入、推荐和修改条件。

## 5. 常见问题的通俗回答

### 为什么不是一张问卷？

新手往往不知道哪些信息重要。Agent先从用户自己的话里提取已知条件，再只追问最可能影响推荐的缺口，减少无意义问题。

### 为什么自动测试不用DeepSeek？

真实模型每次措辞可能略有差别，也受网络和额度影响。Mock让同一个测试永远得到同一个结构结果，才能判断是代码退化还是模型波动。Mock只替换模型，不替换业务规则。

### 为什么不展示82分、91分？

数字只是内部排序工具，不是“适合概率”。展示成百分比会制造错误精确感。用户真正需要知道的是为什么合拍、有哪些代价、哪里仍需确认。

### 为什么用SQLite？

第一版主要给个人和身边朋友体验，SQLite不需要额外数据库服务。更重要的是完整会话只存这一处，浏览器和LangGraph都不再保存第二份状态，失败回滚和24小时过期更容易说清楚。

### 哪些是真的，哪些只是原型？

多轮对话、画像、动态追问、冲突与风险、双层匹配、条件修改、重置和失败保护是真实实现。首页、市场、用品、社区、会员中心和“我的”是可点击原型；支付、订单、物流、真实发帖、真实会员和商家联系没有后台。

### DeepSeek到底做了什么？

真人演示使用`DeepSeek-V4-Flash-0731`，API调用名为`deepseek-v4-flash`。它负责画像提取、问题措辞、推荐解释和安全复核；它不能改变确定性代码选出的题目、候选、等级和顺序。

## 6. 失败时怎么演示

- 模型或网络失败：指出旧会话仍然保留，可以原地重试；不要临时伪造一个推荐结果。
- 会话过期：展示创建新会话，不声称可以恢复已经失效的画像。
- 候选不足：允许少于4只或只有方向，不为了页面好看而凑数。
- 公开网址不可用：改用本地Mock演示，并说明公开网址目前只是前端原型分享版。

## 7. 演示前检查

- 不展示或朗读`.env`、API Key、终端环境变量或服务端内部Prompt。
- 使用Mock时明确说“这是稳定演示模式”；使用DeepSeek时说明会产生少量费用且回答可能波动。
- 确认页面标有“Demo虚拟数据”或“Demo演示功能，暂未开放”。
- 不把品种群体倾向说成具体个体保证，不给医疗诊断。
- 不把公开原型网址说成完整FastAPI、SQLite与DeepSeek后端已经部署。
- 实体手机系统安装尚未完成最终手工验证，不提前说“原生App已经安装或上架”。
