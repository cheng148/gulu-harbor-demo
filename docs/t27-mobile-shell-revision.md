# T27 手机App外壳修订记录

日期：2026-08-13

用户确认第一版虽然使用Web App节约时间和成本，但产品目标仍是手机App。因此T27展示规则修订为：

- 手机打开时占满手机可用宽度。
- 电脑打开时固定为430px手机App宽度并居中，两侧只显示背景。
- 推荐宠物始终保持手机端两列，不再出现桌面四列网页布局。
- 固定底栏始终与手机App容器等宽、等位置。
- 首页内容、配色、插画、搜索、分类和Demo数据说明保持不变。

验证证据：新增1条防回归测试，前端全量6条测试、ESLint、TypeScript与生产构建通过；真实浏览器在390×844、430×932和1280×900视口验证无横向溢出，电脑端容器宽430px，宠物两列，底栏宽430px，控制台无错误。
